# Usage Guide

This guide covers advanced usage scenarios and features of PyGUIzer, beyond the basic quick start examples.

## Multiple Functions

PyGUIzer supports multiple functions in a single file, either through auto-registration or decorators:

### Auto-Registration

```python
# multiple_functions.py
def add(a: int, b: int) -> int:
    """Add two numbers together."""
    return a + b

def subtract(a: int, b: int) -> int:
    """Subtract two numbers."""
    return a - b

def multiply(a: int, b: int) -> int:
    """Multiply two numbers."""
    return a * b

def divide(a: int, b: int) -> float:
    """Divide two numbers."""
    if b == 0:
        raise ValueError("Cannot divide by zero")
    return a / b
```

Run with:
```bash
python -m pyguizer run multiple_functions.py
```

### Decorator-Based

```python
# app.py
from pyguizer import PyGUIzer

app = PyGUIzer()

@app
def process_text(text: str, uppercase: bool = False, strip: bool = True) -> str:
    """Process text by applying transformations."""
    if strip:
        text = text.strip()
    if uppercase:
        text = text.upper()
    return text

@app
def count_words(text: str) -> int:
    """Count the number of words in a text string."""
    if not text:
        return 0
    return len(text.split())

@app
def get_word_stats(text: str) -> dict:
    """Get detailed word statistics from text."""
    words = text.split()
    word_count = len(words)
    unique_words = len(set(words))
    avg_word_length = (
        sum(len(word) for word in words) / word_count if word_count > 0 else 0
    )

    return {
        "word_count": word_count,
        "unique_words": unique_words,
        "avg_word_length": round(avg_word_length, 2),
        "total_characters": len(text),
    }

if __name__ == "__main__":
    app.run(title="Text Processing App", port=8000)
```

## Preset Management

PyGUIzer includes a preset management system that allows users to save and load input configurations:

```python
from pyguizer import PyGUIzer
from typing import List, Optional

app = PyGUIzer()

@app
def advanced_calculator(
    number1: float,
    number2: float,
    operation: str = "add",
    precision: int = 2,
    use_scientific: bool = False
) -> float:
    """Perform advanced calculations with different options."""
    operations = {
        "add": lambda x, y: x + y,
        "subtract": lambda x, y: x - y,
        "multiply": lambda x, y: x * y,
        "divide": lambda x, y: x / y if y != 0 else 0
    }
    
    result = operations.get(operation, operations["add"])(number1, number2)
    
    if use_scientific:
        return float(f"{result:.{precision}e}")
    else:
        return round(result, precision)

if __name__ == "__main__":
    app.run(title="Advanced Calculator", port=8000)
```

### Using Presets in the UI

1. Fill in your desired inputs
2. Click "Save Current Inputs as Preset" to save
3. Enter a name and optional description
4. Load presets later from the preset list
5. Delete presets you no longer need

PyGUIzer supports markdown rendering for rich output display:

## Batch Processing

PyGUIzer supports batch processing of multiple function calls:

```python
from pyguizer import PyGUIzer
from typing import List

app = PyGUIzer()

@app
def process_numbers(numbers: List[int], operation: str = "sum") -> dict:
    """Process a list of numbers with different operations."""
    if not numbers:
        return {"error": "No numbers provided"}
    
    if operation == "sum":
        result = sum(numbers)
    elif operation == "average":
        result = sum(numbers) / len(numbers)
    elif operation == "max":
        result = max(numbers)
    elif operation == "min":
        result = min(numbers)
    else:
        return {"error": f"Invalid operation: {operation}"}
    
    return {
        "operation": operation,
        "result": round(result, 2) if isinstance(result, float) else result,
        "count": len(numbers),
        "numbers": numbers
    }

@app
def analyze_data(data: List[float]) -> dict:
    """Analyze a list of data points."""
    if not data:
        return {"error": "No data provided"}
    
    return {
        "count": len(data),
        "sum": sum(data),
        "average": sum(data) / len(data),
        "min": min(data),
        "max": max(data),
        "range": max(data) - min(data)
    }

if __name__ == "__main__":
    app.run(title="Data Processing App", port=8000)
```

## File Uploads

PyGUIzer supports file uploads through the `Path` type:

```python
from pyguizer import PyGUIzer
from pathlib import Path

app = PyGUIzer()

@app
def process_file(file: Path, operation: str = "analyze") -> dict:
    """Process an uploaded file with different operations."""
    if not file.exists():
        return {"error": "File not found"}
    
    try:
        with open(file, 'r') as f:
            content = f.read()
        
        lines = content.split('\n')
        words = content.split()
        
        return {
            "operation": operation,
            "file_name": file.name,
            "file_size": file.stat().st_size,
            "line_count": len(lines),
            "word_count": len(words),
            "character_count": len(content),
            "success": True
        }
    except Exception as e:
        return {
            "error": f"Error processing file: {str(e)}",
            "success": False
        }

if __name__ == "__main__":
    app.run(title="File Processor", port=8000)
```

## Async Function Support

PyGUIzer now supports both synchronous and asynchronous Python functions:

### Synchronous Functions

```python
from pyguizer import PyGUIzer
import time

app = PyGUIzer()

@app
def sync_function(x: int, y: int) -> int:
    """Synchronous function that sleeps to simulate work."""
    time.sleep(1)  # Simulate blocking work
    return x + y

if __name__ == "__main__":
    app.run(title="Sync Function App", port=8000)
```

### Asynchronous Functions

```python
from pyguizer import PyGUIzer
import asyncio

app = PyGUIzer()

@app
async def async_function(x: int, y: int) -> int:
    """Asynchronous function that sleeps to simulate work."""
    await asyncio.sleep(1)  # Simulate non-blocking work
    return x * y

@app
async def async_data_processor(data: List[int]) -> dict:
    """Asynchronous function that processes a list of data."""
    await asyncio.sleep(0.5)  # Simulate work
    return {
        "sum": sum(data),
        "average": sum(data) / len(data) if data else 0,
        "max": max(data) if data else 0,
        "min": min(data) if data else 0
    }

if __name__ == "__main__":
    app.run(title="Async Function App", port=8000)
```

### How It Works

PyGUIzer automatically detects if a function is synchronous or asynchronous:

- **Synchronous functions**: Run in an executor to avoid blocking the event loop
- **Asynchronous functions**: Directly awaited for optimal performance

## Concurrent Batch Processing

Batch requests are now processed concurrently for improved performance:

```python
# Example batch request sent to /api/batch
{
  "functions": [
    {
      "name": "sync_function",
      "inputs": {
        "x": 10,
        "y": 20
      }
    },
    {
      "name": "async_function",
      "inputs": {
        "x": 5,
        "y": 6
      }
    },
    {
      "name": "sync_function",
      "inputs": {
        "x": 100,
        "y": 200
      }
    }
  ]
}
```

### Benefits

- **Improved performance**: Multiple functions run in parallel
- **Reduced latency**: Faster response times for batch requests
- **Better resource utilization**: Efficient use of system resources
- **Order preservation**: Results are returned in the original request order

## Best Practices

### For Async Functions

1. **Use asyncio.sleep() instead of time.sleep()** to avoid blocking the event loop
2. **Leverage async libraries** (like aiohttp) for I/O operations
3. **Keep CPU-bound work minimal** in async functions, or use executors for CPU-intensive tasks

### For Batch Processing

1. **Group related functions** in batch requests to take advantage of concurrency
2. **Limit batch size** to avoid overwhelming system resources
3. **Handle errors gracefully** as each function in a batch runs independently
